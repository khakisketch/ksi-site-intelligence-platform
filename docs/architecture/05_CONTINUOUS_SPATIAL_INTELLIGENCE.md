# Continuous Spatial Intelligence

## Baseline first

A new site is mapped and processed before verified autonomy. Edge may use a provisional sparse map only for conservative operation.

## Daily mission

Every patrol includes a spatial capture backbone. Event investigations may divert the aircraft, followed by coverage recovery.

## Post-flight

Processing reconstructs or updates the site model, detects change, publishes a new world model version and prepares the next mission package.

## Remap triggers

- model/image registration error
- new large structures or material stacks
- repeated blocked routes
- scaffold/crane/container relocation
- coverage or reconstruction quality failure
- construction phase change

## Expert mapping

Survey-grade mapping remains an expert mode when contractual accuracy, GCP or strict GSD is required.
