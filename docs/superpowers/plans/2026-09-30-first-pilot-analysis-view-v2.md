## Product acceptance

The same immutable Analysis ID, result ID, cut/fill/net values, suitability state, limitations, and evidence digests appear in Core API, Dashboard, and Codex MCP. A report with the maximum valid coverage masks never puts those masks in structured V2 responses. Each API/MCP structured response is at most 512 KiB; lists have at most 50 items; evidence and full coverage require separate scoped requests. V1 journals/calculation contracts remain readable and unchanged. This does not establish customer Terra compatibility or field accuracy.

## Contract decisions

- Add V2 read and create paths and `AnalysisViewV2`; leave V1 wire paths and durable AP/NX records intact. V2 create reuses the validated two-selector V1 request and returns the compact V2 view, including idempotent retries after completion. V2 projects Core's existing result, without recomputation or revising history.
- Detail returns IDs, timestamps, execution/suitability, cut/fill/net, `uncertaintyM3=null` for provisional accuracy, limitations, compact coverage counts/areas/bounds, report and coverage digests, and scoped links. It never embeds mask base64.
- List uses a smaller item projection with opaque keyset pagination over immutable `(createdAt, analysisId)`, maximum 50 per page. Every page reapplies authenticated Site and WorkArea grants and live AI consent for MCP.
- Evidence has a bounded page size and opaque cursor bound to the Analysis ID and current evidence revision/digest; a changed revision requires restarting pagination. Typed, self-contained page items expose epoch CRS/vertical/inspection facts, calculation policy/runtime identity, evaluation outcomes, individual checkpoint facts, exact references and limitations without omission. The page endpoint is the scoped access path; an item has its own link only when an existing scoped resolver actually serves it.
- Full coverage is a separate canonical byte resource from the immutable report. Require one valid HTTP byte Range per request, at most 64 KiB, and recheck identity, Site/WorkArea scope, and live MCP consent for every range. Return digest and total length; reject missing, multi-range, or oversized ranges without returning full bytes.
- Enforce the 512 KiB ceiling on actual serialized API and MCP responses, including maximum-size contract fixtures. A pathological record fails explicitly instead of returning a truncated or misleading result.
