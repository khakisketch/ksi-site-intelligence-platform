# Executable design prototypes

`design/` contains disposable or reviewable prototype source and visual studies. It is not product
authority and is not automatically part of the Dashboard runtime.

- `ksi-operations-console-a-prototype/`: disposable runnable Console prototype and generated local outputs. Its local `AGENTS.md` is audit-tracked historical material; it is not active product instruction. Current Console design is the ledger/spec below.
- `ksi-site-intelligence/`: static screen/study generator and generated studies.

Adopted UI constraints belong in `../design-system/`; durable decision/audit prose belongs in `../docs/`.
Generated `dist`, screenshots, test results, caches, and dependency trees remain ignored under their
prototype owner and are not acceptance evidence without a dated record.

Current Console design direction: [`../docs/design/CONSOLE_CURRENT_SPEC.md`](../docs/design/CONSOLE_CURRENT_SPEC.md); the ledger index is [`../docs/ledger/DESIGN.md`](../docs/ledger/DESIGN.md).
