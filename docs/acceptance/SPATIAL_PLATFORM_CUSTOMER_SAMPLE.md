# 첫 공간데이터 파일럿의 고객 표본 안내

이 문서는 자료 요청 범위를 설명한다. 현재 고객 자료를 받았거나 DJI Terra의 모든 export 형식을
검증했다는 기록이 아니다. 원본 사진이나 비행 제어 권한은 첫 검증에 필요하지 않다.

## 최소 자료

| 자료 | 목적 | 최소 확인 정보 |
| --- | --- | --- |
| 같은 현장·작업구역의 `t0`, `t1`, `t2` DSM | `t0→t1`, `t1→t2` 상대 지형 변화 분석과 반복 입력 확인 | 각 파일의 GeoTIFF 원본 바이트, 촬영 기간, 수평 CRS, 높이 기준·단위, NoData, 처리 보고서, 파일별 SHA-256 |
| 같은 현장의 정사영상 한 시점 이상 | 외부 코드가 특정 구역의 이미지와 위치 정보를 받아 쓰는 데이터 제공 경로 확인 | GeoTIFF 원본 바이트, 촬영 기간, 수평 CRS, 밴드/해상도, 처리 보고서, 파일별 SHA-256 |
| 작업구역 경계와 실제 요청 구역 | 분석·추출 범위를 같은 좌표 기준에서 확인 | 경계 파일 또는 좌표 목록, CRS, 현장 담당자가 의도한 구역 설명 |
| 가능한 검사점 또는 측량 비교 근거 | 정확도 평가 | 검사점 좌표·높이·기준·시점·측정 방법. 없으면 조건을 충족한 분석도 정확도 미검증 잠정값으로만 표시 |
| 자료 사용 범위 | KSI 저장·처리·전송의 권한 확인 | 누가 업로드/조회/외부 AI에 제공할 수 있는지, 보관·삭제·재사용 조건 |

DSM은 높이 격자, 정사영상은 좌표가 붙은 현장 사진 지도다. 첫 두 경로에는 이 둘이면 된다.
Point cloud와 3D Mesh는 초기 검증 필수 자료가 아니다. 별도 활용 요구가 확정될 때 샘플과
형식·축·단위·텍스처/속성 계약을 받는다.

고객 담당자가 제공하기 편한 방식은 Terra에서 내보낸 파일을 **변환하지 않은 채** 각 조사일별
폴더에 두고, 함께 생성된 처리 보고서를 붙이는 것이다. KSI 담당자가 해시·포맷·좌표·권리·
누락 항목을 기록한다. 헤더의 EPSG 코드만으로 수직 기준이나 정확도를 추정하지 않는다.
지원되지 않는 포맷, 좌표/높이 정보 부족, 손상, 용도별 검사 실패는 보완 사유를 반환한다.

고객 로그인 연동의 issuer·audience·JWKS 값과 시험 계정은 고객 IT 담당자와 KSI 운영자가
배포 단계에서 교환한다. 현장 담당자에게 이 값을 직접 만들거나 채팅에 비밀값을 적도록
요구하지 않는다. 운영 호스트·자격증명 설치는 별도 승인과 검증을 거친다.

수용은 코드의 합성 GeoTIFF 테스트와 구분한다. 동일 자산 ID와 관측 revision으로 두 주기의
분석, 구역 데이터 활용, API/MCP/화면 일치, 업무 시간과 고객 사용 범위를 확인해야 한다.
