# ADR-KSI-042 — 현장 메뉴 공간·분석

- Status: Accepted
- Date: 2026-11-14
- Supersedes: ADR-KSI-026의 현장 메뉴 구성과 2026-10-26 콘솔의 공간·자료 별도 뷰어 결정

## 맥락

현장 작업은 조직 작업 목록의 현장 필터와 겹쳤다. 공간과 자료는 같은 종류의 뷰어를 쓰고
있었고, 분석 실행과 결과 검토는 여러 이름으로 흩어져 있었다.

## 결정

전역은 홈·현장·작업·계정·도움말이다. 데스크톱과 모바일의 현장 메뉴는 공간과 분석으로
통일한다. 현장 설정은 현장 이름 옆의 별도 진입이다. 모바일 하단에는 홈·현장·작업·계정을 둔다.

| 위치 | 주소 | 책임 | 제외 |
|---|---|---|---|
| 공간 | `/sites/{id}` | 자료 등록 진입·검사 상태·관측 열람·두 시점 비교·작업구역 선택과 관리 | 분석 요청과 결과 검토 |
| 분석 | `/sites/{id}/analysis`, `/sites/{id}/observations…`, `/sites/{id}?mode=results` | 변화 분석 요청·이력·결과 검토, 외부 비교 | 자료 등록 |
| 현장 설정 | `/sites/{id}?section=manage` | 현장 범위·상태, 작업구역 관리 진입 | 자료·분석 |
| 작업 | `/field…` | 조직의 등록·검사 진행, 받은 작업, 팀 관리와 현장 필터 | 별도 현장 작업 메뉴 |

최상위 메뉴, 상단 바, 본문은 공간과 분석의 명칭을 함께 쓴다. 분석 결과 상세의 제목은
분석 결과다. 작업구역과 전역 작업의 명칭은 유지한다.

공간은 뷰어 한 곳에 자료·등록 진행 패널과 선택 자료 정보를 둔다. 등록 진행에서
`/field?site={id}`로 이어지고, 작업 상세에서는 같은 현장의 등록 진행으로 돌아올 수
있다. 작업구역 관리와 구역 자료 준비는 공간의 하위 경로다. 이후 3D 열람이 제품에
들어오면 공간의 보기 방식에 추가한다.

분석은 변화 분석·외부 비교 탭으로 나눈다. 변화 분석은 이력이 기본이며 새 분석 요청으로
폼을 연다. 결과 상세는 입력 시점, 상태·준비도, 값, 근거·한계 순서로 보여 준다.

## 기존 주소

- `/spatial-assets`는 공간의 자료 패널로 옮긴다. 조회 조건과 선택 자료를 유지한다.
  기존 A/B 요청은 두 시점 비교로 옮길 수 있는 조건일 때 두 참조를 유지하고 그 외에는 A를 유지한다.
- `?section=work-orders`는 공간의 등록 진행으로 옮긴다. 이전 탭 키는 가장 가까운
  현행 영역으로 연결한다.
- 외부 비교와 분석 결과의 직접 주소는 유지하며 분석을 활성화한다.

기존 Core 권한, 등록·검사·분석 계약, 결과의 증거와 수락 범위를 유지한다.
