# KSI Site Intelligence Product Constitution

## 제품 정체성

KSI Site Intelligence Platform은 **물리적 현장의 관측을 사람·외부 에이전트·소프트웨어·로보틱스가 재사용하는 근거형 Site State와 Change로 바꾸는 기반이다.**
건설·토공 운영이 첫 시장이며, 플랫폼의 배타적 정체성이 아니다. 외부에서 생성한 현장
공간데이터의 등록·검사·구조화는 그 관측 입구이며, 필요한 공간데이터를 제공하는 데이터 제공과
재현 가능한 결과를 내놓는 고정 분석의 두 경로를 갖는다. 공통 Core가 자산·시점·구역·버전,
권한·용도별 적합성·작업·결과·계보·근거를 소유하며 UI·MCP·향후 SDK/CLI는 그 계약을
사용한다. 분석 파사드와 클라이언트는 별도 계산·권위를 만들지 않는다(ADR-KSI-038).

현재 개발은 **기존 사진측량 소프트웨어의 산출물을 활용하는 전문 분석 플랫폼**에 집중한다.
원본 사진 처리·매핑·재구성은 외부 전문 소프트웨어의 역할이며 KSI의 개발·실행 범위가 아니다.
KSI의 핵심 책임은 알고리즘 전부의 자체 구현이 아니라 현장·시점·작업구역 관리, 용도별 품질
판정, 재현 가능한 비교·분석, 결과 해석·이력·근거·보고를 하나의 업무로 완성하는 것이다.
검증된 외부 기술을 선택적으로 재사용하되 정상 구현을 보존하고 불필요한 의존성·플랫폼을
늘리지 않는다. 자체 구현은 외부 기술로 해결할 수 없음이 입증될 때만 개발한다. 구체적 범위는 [제품 요구사항](MASTER_PRD_v3.0.md), 채택 절차는
[개발 지침](../../AGENTS.md)을 따른다.

이 두 경로는 별개 제품이 아니라 **같은 공통 업무 계약을 소비하는 두 가지 방식**이다. 고객
가치는 자료 탐색·공간 전처리·반복 연산·권한·계보·근거 관리를 프로젝트마다 다시 구축하는
부담을 줄이는 것이며, 시간·비용 절감은 실제 사용으로 검증한다(ADR-KSI-038 D1). 이때
'제출된 원본'은 고객이 KSI에 제출한 산출물 바이트를 뜻하며, 고객의 촬영 원본 전체를
수집·보관한다는 의미가 아니다. 이때
`Site State와 Change`는 **관측 범위·관측 시각·유효 조건·미확인 영역·최신성·변경 이력을 가진
버전화된 현장 관측 기록**을 뜻한다. 실시간 디지털트윈이나 현장 전체 상태의 완전 추론을
주장하지 않으며, 이미 관측된 일부 자료에 대한 근거다.

판정은 세 층으로 구분한다. **자료 자체의 유효성**(형식·좌표/수직기준·격자/해상도/NoData·
바이트 봉인 일치), **목적별 사용 적합성**(열람·추출·높이 비교·상대 체적 등 개별 용도의 조건
충족), **분석 결과의 재현 가능성**(입력·구역·프로필·정책·근거 digest 결속에 계산 엔진
버전과 주요 연산 설정을 포함한 동일 결과 재검증)이다.

정량 분석은 해당 분석에 필요한 공간 기준과 품질 조건을 충족하는 근거가 **기계적으로
검증된 경우에만** 허용한다. 제공자 선언은 근거로 사용할 수 있으나, 그 자체로 관측 사실이나
검증 결과가 되지 않는다. 정량 조건이 충족되지 않은 자료가 허용된 열람·추출까지 함께 막히지는
않으며, 열람 가능하다고 정량 사용 가능을 뜻하지도 않는다. 동일 조건 재실행은 정의된 수치
허용오차 내에서 일치함을 검증 대상으로 하며, 버전이 바뀐 계산은 별도 결과로 남긴다.

계산 결과·근거는 불변·가산 기록으로 보존하고, 현재 활용 가능 여부는 적용된 정책과 증거
버전에 종속된 **별도 투영**으로만 판단한다. 정량 활용이 차단되더라도 감사·재현을 위한 역사
기록 자체는 삭제하거나 봉쇄하지 않는다. 과거 계산값이 존재한다는 사실과, 그 값을 지금
의사결정에 사용해도 된다는 판단은 다르다.

신뢰성 원칙은 장기 불변식으로 고정하고, 허용 CRS·증거 형태·품질 임계값은 버전이 있는
정책과 분석 프로파일의 영역으로 둔다. 이 경계를 유지해야 지원 범위를 확장해도 신뢰성이
훼손되지 않는다.

첫 실증은 건설 토공이며, WorkArea별 **반복 관측**(`t0→t1` 다음 `t1→t2`)으로 자료 수용부터
분석·근거 조회·사람 검토 연결·다음 관측의 **변경 영향 확인**까지 하나의 공통 기반에서 완결하는
것을 검증한다. 재사용되는 것은 Site·WorkArea 정의와 비교 규칙·연동 흐름이며, 이전 쌍의 계산
authority나 결과를 새 시점에 재사용하지 않는다(ADR-KSI-037).

첫 플랫폼 검증은 DSM·정사영상으로 같은 현장 데이터의 분석 경로와 외부 코드의 구역 데이터
활용 경로를 모두 입증한다. Point cloud·Mesh·외부 분석 레이어·산업별 어댑터는 후속
계약·수용 대상이다. 등록·조회·추출·분석·정확도 평가·사람 검토는 서로 다른 상태다.
표준·포맷 지원이나 구현 완료는 이 정의에서 추론하지 않는다. 상세 책임·미결정 항목은
[ADR-KSI-038](../architecture/ADR-KSI-038-spatial-data-and-analysis-platform.md), 장기 과제는
[SDP-20260930](../superpowers/plans/2026-09-30-spatial-data-platform-roadmap.md)을 따른다.

사용자 경험에서 KSI는 현장 데이터를 AI가 읽어 **무엇이 달라졌고, 왜 중요한지,
지금 무엇을 결정해야 하는지**를 검증된 근거와 함께 제시하고, 사용자의 결정을 다음
관측과 업무로 연결하는 AX 제품이다. AI는 사실 원장을 대체하거나 승인·Mission·비행
명령을 직접 만들지 않는다.

### 에이전트 목표와 실행 경계 (2026-11-11 사용자 결정)

KSI 에이전트의 목표는 업무 완수형이다. 사람이 분석 절차를 지정하지 않아도
에이전트가 자료를 조사하고 필요한 분석을 판단·실행해 근거 있는 업무 결과물까지
완성한다. 실행 권한은 세 층이다. 데이터 탐색·공간 연산·구역 후보 생성·검증된 분석
실행·임시 결과 저장은 자율 실행한다. 정량 결과는 좌표·수직기준·독립 검사점 등
[도메인 불변식](DOMAIN_INVARIANTS.md) INV-053의 검증 조건을 충족할 때만 허용하며,
검증할 수 없는 수치는 생성하지 않는다. 공식 확정·외부 제출·확정 결과 수정은 사용자
승인 후에만 실행한다. 에이전트가 새로 조합한 계산은 검증된 워커의 공식 결과와
구분한다.

첫 검증 목표는 2시점 DSM 변화 전수 조사 → 이상 구역 탐색·지도 표시 → 근거 포함
보고서 초안 생성의 완결이다. 성공 기준은 보고서 파일의 존재가 아니라, 절차
미지정 상태에서의 자율 수행·지도와 결과물 반영·미검증 수치 미생성이다. 이 결정은
EXT-VAL 수락이나 host/customer 수락을 변경하지 않는다.

이 정의는 범위 판정 도구다. Core는 Site·WorkArea·Observation Epoch·버전의 지속적 매핑,
입력 admission, 재현 가능한 계산과 근거, 권한, 결과 조회를 소유한다. LLM은 검증된 도구를
조율할 수 있지만 수치 사실을 추정하거나 계산·사람 검토·발행을 대체하지 않는다.

RTK-equipped Matrice 4D는 초기 현장 검증 장비이자 관측 입력 참조다. 장비는 제품 정의의
중심이 아니며, 고객 통제 현장 PC/DJI Terra 재구성 흐름도 입력 참조일 뿐 KSI의 API·계산
엔진·license/export 지원 약속이 아니다. 건설과 토공 운영이 첫 Vertical이고,
디지털·스마트건설 소프트웨어 파트너는 통합 고객이다. 장기 취득 장비의 제품 책임
경계는 [ADR-KSI-039](../architecture/ADR-KSI-039-physical-site-intelligence-and-acquisition-separation.md)를 따른다.
장기 취득·현장 검증 profile에서는 RC Plus 2/Pilot 2가 사람의 비행 운영과 인터넷 gateway를,
Manifold 3가 인터넷과 독립된 현장 지능을 맡는다. 이 profile은 API-first MVP의 입력
admission·계산·결과 조회 전제가 아니다. RC 인터넷은 새 임무 발급 전에 필요하지만
Manifold SIM은 선택형 Connectivity Add-on이다. 연결 유무와 비행 제어권을 섞지
않으며, 이미 유효하게 활성화된 계약은 서버 연결 단절만으로 취소하지 않는다.

사람의 KSI 업무 화면은 현장 노트북·컴퓨터에서 여는 하나의 반응형
**KSI Operations Console**이다. RC Plus 2/Pilot 2에는 KSI 업무 UI를 표시하지 않고
비행과 gateway 책임만 둔다. 스마트폰은 별도 제품이 아니라 같은 Console의 압축
표현이며 이벤트·분석·근거형 질의에는 사용할 수 있지만 Mission 발급·비행 준비·
WorkOrder·재관측 승인과 장비 전이를 정상 행동으로 제공하지 않는다.

Console Home은 다현장 포트폴리오의 입구다. KSI가 실제 원장에서 확인한 변화·결과·
사람 결정 대기만 현장별 근거와 한계로 요약하며, 공간 결과·보고서·조사 이력은 각
현장이 소유한다. 합성 현장 사진이나 기술 처리 로그로 경영 브리핑을 꾸미지 않는다.

데이터 제공과 지형 변화 분석은 같은 현장·관측의 근거를 소비하는 두 제품 경로다(ADR-KSI-037/038). 업무·Home이 표시하는 모든 현장 상태와 다음 행동은 실제 Core 원장에서 확인된 정보와 사용자 scope를 사용한다. 운영관리용 상대 물량, 추세, 현장 상태와 사람의 검토를 정산·측량·공정 승인으로 승격하지 않는다. 상세 수락 범위는 현재 제품 slice와 acceptance ledger를 따른다.


## 데이터 경로 경계

- PSDK Liveview는 Manifold의 로컬 acquisition/perception 입력이다. Core·Vercel·
  Operations Console이 지속 영상을 중앙 수신하는 것은 핵심 제품 경로가 아니다.
- `EDGE_UPLINK`는 bounded EventBundle/EdgeBundle metadata와 object reference를 전달한다.
  Liveview frame, 원본 사진, RTK/POS stream 또는 공간 산출물 bytes를 운반하지 않는다.
- 외부 첫 출시의 정상 결과 ingress는 `M4D 촬영 → 고객 현장 PC 재구성 → 파생 산출물과
  bounded provenance/품질 근거의 KSI 등록`이다. 원본 사진은 고객 장비에 남는다.
- `SD/저장매체 → 현장 PC → KSI 웹`의 source-media 경로는 별도 승인된 managed/test 입력이며, 외부 첫 출시의 전체 raw-upload 전제가 아니다. 별도 승인·호스트/장비·물리 HIL 수락 전 자동 `MEDIA_PULL`/`MEDIA_UPLOAD` 경로는 비활성 상태다(ADR-KSI-033).

## 승인 결정과 현재 범위

제품 결정의 정본은 [확정 Decision Ledger](FINAL_DECISION_LEDGER_v1.0.md), 제품 방향은 [ADR-KSI-038](../architecture/ADR-KSI-038-spatial-data-and-analysis-platform.md), 현재 취득 책임 경계는 [ADR-KSI-039](../architecture/ADR-KSI-039-physical-site-intelligence-and-acquisition-separation.md)다. Mission·비행·센서 세부 요건은 적용되는 ADR, 안전 불변식과 HIL/현장 수락이 소유한다. 구현 상태는 소스·테스트·현재 작업 원장에서 확인한다. History·acquisition architecture·모듈별 동작을 Constitution에 다시 목록화하지 않는다.

## 참고 구현의 지위

`KSI Platform`, `KSI-Terra`, `KSI-Scout`는 읽기 전용 참고 저장소다. 실행 계약·채택한 알고리즘·라이선스는 KSI 소유의 코드, 스키마, 적용 불변식과 acceptance가 정본이며 `references/repos/`에서 직접 runtime import하지 않는다.
