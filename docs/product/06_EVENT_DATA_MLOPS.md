# Event, Data and MLOps

## Event is the product unit

Detection is not an event. A confirmed event includes entities, spatial relationship, duration, uncertainty, evidence, model/policy/calibration lineage and workflow state.

## Data flywheel

Operational review creates labels. Uncertain, hard-negative and pre/post-active-perception samples are prioritized.

## Model lifecycle

Train -> Offline benchmark -> Replay -> Shadow -> Canary -> Rollout -> Monitor -> Rollback.

## Governance

Customer-specific consent, retention, de-identification and deletion lineage are mandatory.
