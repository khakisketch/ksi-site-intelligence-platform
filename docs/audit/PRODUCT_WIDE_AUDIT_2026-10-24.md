복원(코드·설정·기록 변경 없음):

- Core는 보존 실행 도구 `~/.local/share/ksi-product-use-20261021/run_core_from_preserved_env.py`(원래 env·진입점·데이터 디렉터리 검증 포함)로 재기동해 건강을 확인했다.
- 발급자는 동일 도구·동일 client secret(호스트 사본과 Docker 볼륨 시크릿의 SHA256 일치 확인)으로 `--issuer-origin https://...:10011 --dashboard-origin https://...:10010 --port 9042`로 재기동했다. 원래 9042 상태 디렉터리는 확인되지 않아(아마 /tmp 소실) **새 서명 키 상태** `~/.local/share/ksi-product-use-20261021/local-identity-10011`을 만들었다. 교훈/권고: Core·발급자는 자동 재시작 단위가 없다(개발 스택만 `ksi-operations-console-dev.service`가 있다). 감사·재해 복구 관점에서 systemd user unit 또는 문서화된 재시작 런북이 필요하다. 증거 파일은 휘발성 /tmp에 두지 않는다.

## 3. 아키텍처·개발 상태 (독립 코드 감사 결과)

**검증된 런타임 지도** — `apps/dashboard`(Next.js 콘솔), `services/core`(플랫폼 권위: Site/WorkArea/에폭/버전/권한/작업/결과/근거/감사 저널), `services/processing-controller`(측정 워커), `services/analysis-mcp`·`services/spatial-data-mcp`(Core 위 얇은 stdio 어댑터, 각 6개 고정 도구), `packages/`(import-only: domain, event-contracts, geo-core, geo-spatial, change-detection, bim-integration, defect-detection, test-vectors). `services/change-detection` 등 금지 경로 없음. `archive/acquisition-2026/`는 역사 기록으로만 존재하고 런타임 import가 없음(경계 계약 테스트로 고정).

**구현 vs 목표:**

## 4. 디자인·메뉴·사용 흐름 (독립 UI 감사 + 직접 확인)

**전역 셸(홈·현장·업무 + 계정·도움말)**: 모바일 하단 4탭 명확, 데스크톱 레일 일관. 수용 가능.

**현장 화면 정보구조 — 설계 재검토 필요.** 주요 근거(원본 캡처 기준):

1. **현장 내 내비게이션 과중**: 사이트 탭(`작업공간|자료|결과|설정·정보`) 아래 또 같은 스타일의 필 행(`목록|작업구역…|단일 시점|두 시점 비교|정보`)이 겹쳐 3층 내비가 영상보다 무겁다. 390에서는 4~5행으로 감기 전 단계가 없다.
2. **비교 이중**: 작업공간의 `두 시점 비교`와 자료의 `나란히`가 거의 같은 A/B 선택+만료 무대를 제공하며 문구만 다르다. "어디서 비교하나"에 답이 둘.
3. **결과 다음 행동 미로**: 요약 카드 위아래로 `작업공간에서 결과 보기|근거 확인|계보|독립 보기로 돌아가기×3|이력` 링크가 분산되고 1차 행동이 모호하다. 기록 우선 방향 자체는 옳다.
4. **데스크톱 계정·도움말 발견 불가**: 모바일엔 4탭이 있지만 데스크톱 레일엔 없고(푸터 사용자 영역으로만 진입 추정) 지원 경계 안내가 접근하기 어렵다.
5. **홈 냄새 부족**: `확인이 필요한 현장`에 Product Sample Field만 있고 Floreat는 없다. 시각 예시 사이트의 발견성이 떨어지고 카드 밑 빈 공간이 크다. 어휘도 `확인 필요/검토 대기/결정 필요`로 분산.
6. **현장 카드 동질**: 두 카드가 같은 일러스트·같은 배지에 긴 영문 이름으로만 구분되고, `자료·작업 확인/상태 확인/현장 열기` 세 행동의 위계가 없다.
7. **디자인 예시 진입 위치**: 자료 도구 모음의 `디자인 예시 보기`가 보기 모드처럼 읽힌다. 배지·출처·복귀 링크는 정확하므로 완화된 문제.
8. **모바일 제어 행 선점**: 390에서 A/B 풀폭 행+층 행이 2~3스크롤 무대를 밀어낸다. 넘침·접근성 위반은 없음(기록된 검사).

**지금 좋은 것(보존)**: 만료 상태의 정직성(어두운 무대+사유+단일 복구, 가짜 픽셀·거대 범위 도형 없음), 칸별 날짜/층 제어와 날짜-만 한정 표시, 기록 우선 결과와 "계산 입력≠탐색 선택" 구분, 예시의 완전한 격리(배지·출처·CC BY 4.0), 일관된 타입 스케일·버튼 위계, 18개 상태 모두 가로 넘침/axe WCAG2A·AA 위반 0.
