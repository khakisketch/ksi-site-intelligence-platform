- [ ] 기존 코드와 신규 요구사항이 같은 문제를 해결한다.

## 3. 안전·아키텍처

- [ ] 서버 응답이 없더라도 비행안전이 유지된다.
- [ ] Edge 제어권 원칙을 위반하지 않는다.
- [ ] DJI Flight Controller와 책임이 구분된다.
- [ ] 수동 Polygon을 동적 위험의 주 수단으로 만들지 않는다.
- [ ] 불확실성을 숨기지 않는다.
- [ ] 실패사유를 기록한다.

## 4. 데이터

- [ ] 원본 관측과 결과 계보가 유지된다.
- [ ] 모델·정책·코드 버전을 기록한다.
- [ ] 테넌트 격리를 검증한다.
- [ ] 개인정보 보존정책을 확인한다.
- [ ] 학습데이터 사용권한을 확인한다.

## 5. 테스트

- [ ] 기존 테스트를 확인했다.
- [ ] Golden Test Vector를 만들었다.
- [ ] 신규 런타임에서 회귀검증했다.
- [ ] 실제 데이터 흐름으로 E2E를 검증했다.
- [ ] 실패·통신두절·재시작을 검증했다.
- [ ] 결과가 UI에서 재현된다.
