# Console desktop-first UX — work entry

Status: verified increment; active follow-ups remain.
Owner: Build.
Started: 2026-10-26.

## Goal

Make the Operations Console a desktop-first, site-centric operational surface: the current site is
obvious, the spatial stage is the hero, materials are scannable, and expired data is still shown
honestly as registered extents rather than empty boxes.

## Delivered

- Site context in the desktop rail: current site + 작업공간/자료/관측 작업/결과; site switcher
  preserves the section. Site header tabs hidden at `lg+`, retained below.
  Commit `1b8ed545`.
- Materials desktop: persistent catalog + stage + compact inspector; long details collapse;
  preparation request form in a native dialog; list group/date and filename truncation fixed.
  Commit `589490ca`.
- Expired extent canvas: file/work-area extent, actual prepared-window bounds, dimensions, pixel
  size; no fake pixels. Commit `49d19a3d`.
- Current design spec and archived superseded boards.

## Viewer-first implementation

Branch `viewer-first-20261026` from `49d19a3d`; product commit `4879a05e`. Production image
`ksi-product-dashboard:viewer-first-20261026`
`sha256:8efc8dc2eb56746ef062068a48c93bf0a3915cca0a0b3a75f9514279323a4a50`.
Previous container retained as `ksi-product-console-pre-viewer-first-20261026`.

- `/sites/{id}` workspace and `/sites/{id}/spatial-assets` use a 56px icon rail at `lg+`;
  global top bar and site header are hidden there. `?section=manage`, `?section=work-orders`,
  `?section=results`, `?mode=results`, analysis, observations and work-area screens keep the
  labelled 176/232px rail, top bar and site header.
- Viewer starts with the **full canvas**. The floating layer panel (300px) and inspector (332px)
  open from the toolbar, are collapsible, and are not forced open. The closed layer toggle keeps
  the current site name visible at `xl`. Escape/focus return preserved.
- Home and site list use a consistent 16:9 neutral cover when no prepared preview exists. The
  cover says it is not imagery; no synthetic landscape, extent, or accuracy claim. Real prepared
  pixels replace it when available. Home "다른 현장" rows carry a compact mark cover.
- Mobile site header has a compact **현장 변경** sheet; changing sites preserves the active
  section. The sheet is focus-managed and closes with Escape/backdrop.
- Materials: full-bleed stage, in-canvas pane head hidden in viewer mode because the layer panel
  owns selection. Site workspace: controls inset past the open panel, real extent canvas enabled.
- Mobile keeps the existing site header, top bar, bottom nav, catalog/inspector sheets.
- Request dialog, site-switch section preservation, dense/viewer client navigation, panel/info
  close-reopen, and Escape were exercised on production.
