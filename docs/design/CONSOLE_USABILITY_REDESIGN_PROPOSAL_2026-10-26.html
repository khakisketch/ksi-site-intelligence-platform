04

만료 복구: 이력 페이지가 아니라 요청에서 끝내기

현재는 `구역 자료 준비에서 확인`이 이력만 있는 화면으로 보냅니다. 제안은 선택한 자료의 준비 요청을 그 자리에서 만들고, 이력은 보조 링크로 분리합니다.

만료 → 이력 페이지 → 생성 버튼 없음

만료 안내→구역 자료 준비→이력만

05

등록: 이름과 단계를 실제 동작에 맞춘다

`자료 등록`을 누르면 파일 업로드가 아니라 관측 작업 생성이 나옵니다. 작업 만들기와 파일 제출을 이름·단계로 분리합니다.

Step 1 · 작업

관측 작업 만들기

현장과 작업구역, 작업 이름을 정합니다. 이 단계에서는 파일을 올리지 않습니다.

작업 이름 · 9월 6일 현황 비교
작업구역 · Floreat common-extent
작업이 만들어지면 파일 제출 단계로 이동합니다.
Step 2 · 파일

파일 제출

작업에 사용할 정사영상·DSM을 올립니다. 파일 검사는 제출 뒤 별도로 진행됩니다.

파일을 끌어 놓거나 선택
제출 ≠ 검사 완료 ≠ 분석 가능. 각각 다른 상태로 표시합니다.
Step 3 · 검사

검사 확인

제출 파일의 형식·격자·좌표 기준을 확인합니다. 실패·보완 사유는 여기서만 읽습니다.

검사 상태 · 파일 정보 확인됨
분석 적합성 · 이 화면에서 판정하지 않음
LABEL`자료 등록`이라는 이름은 파일을 올리는 화면에만 씁니다. 관측 작업을 만드는 화면은 `관측 작업 만들기`, 파일을 올리는 화면은 `파일 제출`로 부릅니다.
06

상세와 폭: 맥락을 유지하고, 창 폭을 설명한다

작업 상세에서 전역 업무 탭을 제거하고, 단계·담당·기한을 한눈에 둡니다. 1024px 게이트는 기기 이름이 아니라 창 폭과 해결 방법을 말합니다.
