# 자료 우선 재구성 — A 너비 유지, 텍스트·알림 분리

상태: Human 피드백에 따른 **비교 프로토타입**. 운영 적용·최종 레이아웃 승인이 아니다.
기존 `CONSOLE_LAYOUT_CHOICES_20261027.*`, `CONSOLE_LAYOUT_RESEARCH_20261027.*`와 해당 서버는 보존한다.
자료·권한·보관·정량 활용·V2/V3 계약과 `CONSOLE_CURRENT_SPEC.md`의 현행 권위는 변경하지 않는다.

## 이번 피드백에서 고정한 것

- C의 넓은 자료 표를 공간 탐색의 기본으로 밀지 않는다. 목록이 주인공이 된다는 지적을 수용한다.
- A의 목록 너비(1440에서 336px, 1000에서 300px)를 유지한다.
- 큰 미리보기 제목, 반복 설명, 기본 열린 핵심 사실, 하단 A/B 배정표를 공간 화면에서 제거한다.
- 단일/두 시점 모두 같은 목록·큰 stage를 사용한다. A/B 선택은 작은 자료 목록에서 한다.
- 파일명·CRS·출처 상세는 요청 시 비모달 정보 팝오버. 매번 화면을 막는 정보 모달은 사용하지 않는다.
- 자료를 더 크게 볼 때는 명시적인 `화면 넓게`로 메뉴를 접는다. 자동 접힘이나 선택 해제는 없다.
  전체 크롭을 유지하는 맞춤 표시가 기본이며, 크게 보이게 하려고 숨겨진 크롭/정합을 하지 않는다.

## 오류·알림의 위치

| 종류 | 표시 | 닫은 뒤 / 복구 |
|---|---|---|
| 화면 전체 목록 갱신 오류 | 앱 상단 고정 위치의 작은 비모달 알림. 목록·stage 크기는 바뀌지 않음 | 자동 만료 없음. 닫아도 알림 버튼의 개수·내역에 남고 재시도 가능 |
| 갱신 중 | 상단 알림 상태와 작은 아이콘. 기존 자료 유지 | 완료 예시로 복귀. 측정·데이터 성공으로 표현하지 않음 |
| 특정 자료의 표시 문제·만료 | 해당 자료 행/미리보기의 상태 배지. 클릭 시 해당 자료 설명·복구 팝오버 | 다른 자료 계속 탐색. 사용할 수 없는 크롭을 다른 이미지로 대체하지 않음 |
| 자료 종류 불일치 | 두 시점 도구 영역의 작은 상태 배지, 클릭해 설명/같은 종류 맞춤 | 목록을 늘리는 경고문 없음 |
| 세션 만료처럼 전체 작업이 막힌 상태 | 선택이 필요한 native dialog. 배경의 자료는 숨김 | Escape/닫기 허용하되 숨겨진 자료가 다시 나타나지 않음. 재연결은 로컬 상태 예시일 뿐 실제 인증 변경 아님 |

ChatGPT는 사용자가 원하는 **작업면과 알림을 분리하는 방향**의 비유로 사용한다.
ChatGPT 오류 동작을 실제 계정에서 조사·복제했다는 주장은 하지 않는다.
일반 정보·성공·사소한 오류를 일괄 모달로 바꾸지 않는다. 배지에는 텍스트를 포함하고,
알림은 기존 live region으로 알리며, 팝오버/모달 닫기와 포커스 복귀를 검증한다.

## Direction contract (development-only)

**THESIS:** 목록은 고르는 곳, stage는 자료를 보는 곳. 설명 문서처럼 보이던 공간 영역을 실제 크롭이 지배하게 한다.
**OWN-WORLD:** 기존 중립 KSI 팔레트·labelled rail·A 목록 너비·한글 UI 글꼴 계승. 테마/브랜드 변경 없음.
**STORY:** 현장·구역을 확인하고 자료를 고른 뒤 큰 화면을 본다. 문제가 있는 자료만 배지로 설명을 열고, 전체 오류는 공간과 분리해서 복구한다.
**FIRST VIEWPORT:** 얇은 비교 도구 띠, 48px 현장/보기 막대, A 너비 목록, 나머지 높이를 쓰는 영상. 두 시점은 하단 배정표 없이 같은 stage 안에서 병렬 표시. 정보는 기본 닫힘.
**FORM:** 사용자가 A의 너비와 visual-first를 명시한 국소 구성 수정, Operate/code-led. 새 A/B/C 대회나 세계관 변경 없이 단일/두 시점 동작을 보여준다.
**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance. 기존 디자인 정본은 보존하며 이 companion과 sidecar에 비교본 증거만 남긴다.

## 작은 화면과 자료 경계

휴대폰은 자료를 먼저 보여주고 목록은 바로 아래에 둔다. 상단 `자료 4`와 목록의 `보기로` 링크로
오갈 수 있다. 두 시점은 좁은 두 칸 대신 큰 두 장을 세로로 쌓는다. 낮은 데스크톱에서도
보조 텍스트 때문에 stage가 잘리지 않게 한다. 목록을 접는 동작은 사용자가 명시적으로 한다.

기존 Cambridge Coastcare/DataWA Floreat-f3 공개 해안 크롭 4개를 바이트 그대로 사용한다.
CC BY4.0, 출처·KSI 크롭 표기를 유지한다. 실등록·보관 만료 원본 복구·공사 데이터·정합·정량·정확도
증거가 아니며 DSM 수직기준 미확인이다. 원격 요청·등록·계산·실제 계정 변경은 없다.

## 검증 / 남은 선택

비교 프로토타입 범위에서 확인했다. 운영 적용·최종 승인이 아니다.
신규 미리보기는 8858에서 제공하고, 기존 8856/8857은 그대로 둔다.
자료는 공개 해안 크롭 4점을 바이트 그대로 사용하고 CC BY 표기를 유지한다.
등록·보관 만료 복구·정량·정합·정확도 증거가 아니며 DSM 수직기준은 미확인이다.

- 너비·보기: 1440/1280/1024/1000×700/768/390, 단일·두 시점 12조합에서 목록 전체 행 2개 이상,
  목록 너비 336/300px 일치, 페이지 가로 넘침 없음, 데스크톱 stage는 화면 안에 들어간다.
- 접근성·오류: 일반·상태 화면 22건 axe 위반 0건, JS 오류 0건.
  전체 오류 알림은 닫기 전까지 일부 픽셀을 가리지만 목록·stage 크기와 창·헤더 조작은 그대로 둔다.
  알림은 닫아도 내역에 남아 재시도할 수 있고, 팝오버 닫기는 Escape와 포커스 복귀를 확인했다.
  세션 차단 dialog는 닫아도 숨긴 자료가 다시 나타나지 않는다.
- 조작: 단일·두 시점이 같은 목록과 큰 stage를 쓰고, 넓게 보기 전환과 복원 후에도 선택이 유지된다.
  A/B 지정·독립 확대, 화면·새로고침·검색 후 선택 연속성, 휴대폰 점프 링크를 확인했다.

  크롭·늘리기는 하지 않는다. 화면에 칠해진 단일 영상 사각형은 기존 A 대비 1000에서 약 2배,
  1440에서 약 3.4배이며, 지리 면적·정확도가 아니다.
- 새 관점의 독립 검토는 처음 FIX였다. 필수 2건(알림이 정보·확대 버튼을 가림, 닫기 한글 줄바꿈)을
