## 완성선

| 단계 | 증거가 갖춰졌을 때만 사용하는 표현 |
| --- | --- |
| 로컬 기능 연결 | 실제 Core HTTP·저장소·독립 워커로 등록 → 검사 → 적합성 → 계산 → 저장 → 재조회가 성공하고, 필수 정보 누락·알려진 정확도 근거 실패·권한 오류에서는 정해진 상태로 멈춘다. 합성 자료만으로 고객 수용을 주장하지 않는다. |
| 첫 완결 MVP | 고객이 허용한 실제 한 현장·WorkArea에서 `t0→t1`과 `t1→t2`가 각각 입력 결속된 잠정 수치로 기록된다. 두 번째 조사에서 WorkArea·설정·업무 예제를 재사용하되 첫 결과나 pair authority를 재사용하지 않는다. 동일 결과 ID·근거·제한이 UI/API/선택한 Codex MCP 흐름에 나타나며 현장 담당자가 반복 업무를 마친다. 음성 사례와 검토·발행 구분도 확인한다. |
| 첫 고객 운영 가능 | 승인된 환경의 계정·권한·자료 반출·보관·복구·관찰·지원 절차가 준비되고, 고객과 수치의 사용 목적과 제한을 확인한다. 실제 반복 작업의 준비·정리 시간과 실패·보완 사례를 기록한다. 출시·배포와 고객 사용은 별도 승인·수용 기록이 필요하다. 범용 상용 지원이나 측량·정산 정확도 인증을 뜻하지 않는다. |

첫 수치는 `KSI-GIS-RELATIVE-VOLUME-V2`의 **관측된 상대 지형 변화**다. 계산 가능하지만 독립 검사점 평가가 없으면 `PROVISIONAL_ACCURACY_UNVERIFIED`와 `uncertaintyM3 = null`을 반환한다. 평가 실패·상충 또는 필수 좌표/높이/공통 영역 부족은 정상 수치로 우회하지 않는다. RTK FIX, 봉인, 소프트웨어 테스트만으로 절대정확도·공정률·검측·정산 승인을 주장하지 않는다. `INV-017/018/020/024/040/050/051/053/054/055/060/061`과 기존 V1 이력·엄격 정책을 보존한다.

FPC-12는 FPC-03/05의 **실제 종단 증거에 필요한 환경**이다. 소프트웨어 계약·음성 테스트는 호스트 준비와 병행할 수 있지만, 호스트가 없으면 장기 워커 수용을 통과시킬 수 없다. FPC-02/10의 고객 자료 수집도 개발과 병행할 수 있으나 자료가 없는 동안 Terra 지원·현장 정확도·FPC-11 완료는 주장할 수 없다. 준비된 호스트가 없으면 `EXT-VAL-06`의 현 원장상 deferred/release gate를 유지하고 수용 기준 변경은 별도 제품 결정으로만 처리한다.

현재 slice 수용 기준과의 연결: `EXT-VAL-01/02`는 FPC-03, `03`은 FPC-03/04/05, `04`는 FPC-04/07, `05`는 FPC-06/14, `06`은 FPC-12, `07`은 FPC-01/16, `08`은 FPC-17/18에서 각각 입증한다. 첫 요청 계약의 실제 고객 두 주기·정확도 상태·UI/API/Codex 동등성은 FPC-04/08/09/11로 별도 확인한다. 이 연결표는 미완인 항목을 완료로 바꾸지 않는다.

## 처음 실행할 순서

1. **FPC-01:** 실제 코드/테스트·원장과 `EXT-VAL-01..08`을 다시 대조한다. 현재 미커밋 작업과 기존 보호 WIP를 해시로 보존하고, 검사 호스트를 제외하고 즉시 수정할 수 있는 최소 결손을 정한다. 결과는 현재 `EXT-VAL` 원장에 연결한다.
2. **FPC-02를 병행 준비:** 고객에게 요청할 샘플·보고서·좌표/높이·반출 권리 목록을 정리한다. 고객에게 연락하거나 자료를 가져오는 행위 자체는 별도 지시가 필요하다.
3. **FPC-03/04/05를 각기 작은 실행 계획으로 착수:** 우선 기존 검사/정책/계산 코드를 재사용하고, 실제 파일에서 수치까지 연결되지 않는 정확한 끊김만 고친다. 알려진 실패를 잠정 성공으로 바꾸지 않는다.
4. **운영 호스트가 준비되면 FPC-12 종단 증거**를 확보하고 FPC-06..11의 사용자 반복 흐름으로 진행한다. 각 단계에서 코드 테스트, 실제 런타임, 고객 데이터, 현장 수용을 분리해 기록한다.

이 목록은 발견 가능한 현재 요구의 전체 범위다. 새 고객 데이터나 실제 실행에서 드러난 결함은 기존 ID에 귀속하고, 첫 완성선을 바꾸는 새 제품 요구는 승인된 제품 결정으로만 추가한다. BIM 설계면 대비 잔량·범용 BIM 뷰어/편집·자체 재구성·범용 챗봇·로봇/비행 자동 실행·다중 엔진/AI 클라이언트·웹훅·공식 정산/공정률은 이 완료선에 포함하지 않는다.
