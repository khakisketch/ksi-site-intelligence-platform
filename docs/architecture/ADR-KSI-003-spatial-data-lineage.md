# ADR-KSI-003 — 공간 데이터 계보: Point Cloud 원본, Mesh 파생

- 상태: ACCEPTED (2026-07-29, 대표자 확정)
- 관련: MASTER_PRD §15.4, PRODUCT_CONSTITUTION §지도철학, INV-020, INV-024, ADR-008(Provider-agnostic processing)

## 맥락

KSI Processing은 정사영상·Dense Point Cloud·Mesh/Texture/3D Tiles·BIM 정합을 생성한다
(PRD §15.4). 이 산출물들 사이의 권위 관계를 고정하지 않으면, 파생물(Mesh)에서 측정·
분석을 수행하거나 원본 없이 파생물만 보존하는 구현이 조용히 생긴다 — 파생은 손실
변환이라 그 순간 정밀 측정·변화 분석·AI 학습의 상한이 파생물 품질로 내려간다.

## 결정

1. **Point Cloud(+ 처리 파라미터·카메라 포즈)가 공간 데이터의 원본 SSOT다.**
   측정(치수·토공량·변형), 변화 분석, AI 분석, 자율비행용 지도 컴파일은 원본 계열에서
   수행한다.
2. **Mesh·3D Tiles·정사영상·USD는 재생성 가능한 파생 서빙 계층이다.**
   사용자 화면·Digital Twin·시뮬레이션(Isaac Sim 등)·안전계획 UI가 소비한다.
   파생물은 언제든 원본에서 다시 만들 수 있어야 하며, 파생물에서 원본 수준의
   측정·분석을 수행하지 않는다.
3. **파생 방향은 단방향이고 계보를 남긴다.** 모든 파생 산출물은 원본(Point Cloud
   버전·처리 파라미터·Provider)의 참조를 갖는다 — Model Registry의 digest 계보
   (INV-043)와 동형의 원칙이며, 구체 스키마는 Processing 구현 시 확정한다.
4. **LiDAR는 전제가 아니라 옵션이다.** 기본 경로는 사진측량(광각+경사 촬영 →
   재구성)이며, M4D의 센서 구성은 실기 확인 전 가정하지 않는다(SPIKE_REQUIRED
   규율과 동일).
5. 저장·보존 정책은 이 우선순위를 따른다: 원본 계열이 보존 대상의 중심이고,
   파생물은 재생성 비용 대비 캐시로 취급할 수 있다(고객 계약·보존정책 범위 내).

## 결과

- Phase 2(KSI Processing) 구현·감사의 측정 기준이 된다 — "Mesh에서 측정하는 코드",
  "원본 없이 파생만 남기는 저장 정책"은 이 ADR 위반이다.
- 실시간 안전 인식 축(Edge, 카메라 프레임 기반)은 이 결정의 대상이 아니다 —
  재구성 산출물은 비행 후에 존재하므로 실시간 이벤트는 프레임 경로가 정답이다.
  두 축의 접점(지면투영의 평면 가정을 DSM/Point Cloud 지형으로 교체)은 Phase 2
  이후의 개선 항목이다.
