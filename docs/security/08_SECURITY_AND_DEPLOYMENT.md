# Security, Privacy and Deployment

## Modes

- KSI Cloud
- Customer On-Premises
- Hybrid

## Security

- mutual device identity
- signed mission/model packages
- encrypted transport and storage
- tenant isolation
- role-based access
- audit trail
- remote revoke and model rollback

## Privacy

No facial recognition by default. Anonymous tracks, optional face/license plate masking and separate raw/evidence/training retention policies.
