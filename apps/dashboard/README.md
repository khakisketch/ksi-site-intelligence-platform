# KSI Operations Console

The responsive Console is governed by the [current interface contract](../../docs/design/CONSOLE_CURRENT_SPEC.md). Core owns scoped authority and durable records; the Console does not infer suitability or measurement results. Use only current route guidance in source and tests. Local launch, test and build commands are read from `package.json`; repository product, security and data-rights rules enter through [the repository guide](../../AGENTS.md).
