# Adopted product design constraints

`design-system/` contains reviewed visual and interaction rules intended to constrain production UI.
It is distinct from executable prototypes in `../design/` and from audit/history in `../docs/`.

| Path | Product surface |
|---|---|
| `ksi-operations-console/` | KSI Operations Console design context, page guidance, and master rules |

Production application code and tests remain the executable truth; this directory must not claim a
screen is implemented or accepted merely because a design rule exists.
